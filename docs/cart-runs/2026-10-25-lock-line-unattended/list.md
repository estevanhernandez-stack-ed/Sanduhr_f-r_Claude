# Run List: lock-line-unattended

- [x] **1. LockLine: the composer and the one sanitizer, pure, with tests**
  Spec ref: `docs/lock-screen-line-spec.md > Slots`, `> The sanitizer`
  What to build: Read the whole spec first. New `mac/Sources/Sanduhr/Models/LockLine.swift`: `enum LockLine` with
  - `struct Inputs` (plain values: `prefix: String`, `usagePercent: Int?`, `resetsAt: Date?`, `usageStale: Bool`, `waitingCount: Int`, `show: Slots` where `Slots` is an `OptionSet` or struct of three bools for usage, reset, waiting), and `static func compose(_ inputs: Inputs, now: Date, calendar: Calendar, locale: Locale) -> String` returning the line `prefix · Claude 29% · resets 6:10 PM · 1 waiting for you`, slots left out when empty or switched off, joined by " · ". Stale usage gives `Claude usage unavailable` in place of the usage and reset slots. Reset time is local, following the locale's 12 or 24 hour clock (`DateFormatter` with `setLocalizedDateFormatFromTemplate("j:mm")`). Waiting: "1 waiting for you", "3 waiting for you"; 0 leaves it out.
  - `enum SlotKind { case prefix, generated }` and `static func sanitize(_ s: String, kind: SlotKind) -> String?`: strip control characters, newlines, tabs, bidi overrides (U+202A to U+202E, U+2066 to U+2069) and zero-width characters (U+200B to U+200D, U+FEFF); collapse spaces; return nil when the text holds a path (a `/` followed by a word character, `~/`, a drive letter like `C:\`, or a word ending in a file extension such as .swift .md .json .txt .py .ts), an email (`@` between word characters), a URL (`://` or `www.`), a secret shape (reuse `ConfigPack.secretLine(in:)` returning non-nil, and `ConfigPack.looksRandom` per word: do not copy their logic), or any run of 24 or more letters and digits without a space. The prefix is first capped at 32 characters. `static func reason(forPrefix:) -> String?` gives the Settings line explaining why a prefix was dropped ("Left off the lock screen: it looks like a path.", "…an email or a web address.", "…a secret or a key.", "…too long a word.").
  - `static let maxLength = 80`: `compose` runs `sanitize(_, kind: .generated)` on the joined line and, if longer than `maxLength`, drops slots from the right until it fits, never cutting mid-word.
  Tests in `mac/Tests/SanduhrTests/LockLineTests.swift`: the full line; each slot off; stale usage; 0, 1 and 3 waiting; 24-hour locale; and the spec's sanitizer list: a task title with a path ("fix login in src/auth.swift"), a file path, an email, a URL, a token (40 random characters), a bidi override, a 200-character prefix, and a prefix that is fine ("Desk 3"). None of the bad ones may appear in a composed line.
  Acceptance: the tests pass with the suite; no other file changes except Package.swift if tests need registering (they should not).
  Verify: `cd mac && ./build.sh --debug && ./test.sh && ruby smoke/selftest.rb`.
  Stop class: go
