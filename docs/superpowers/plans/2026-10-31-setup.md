# Set up Sanduhr Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the one-way Just the Desk mode with one setup screen of free choices (a nicer desktop, tidy my files, track my AI usage) that opens on first run and can be reopened from the tray and Settings, plus "Design it with an AI chat".

**Architecture:** Core holds the pure parts: the stored setup (`SetupSettings`), the migration from Just the Desk, the change lines, the layout filter, the AI chat prompt and the pasted-answer reader. The App holds a `SetupService` that applies a change through a small host interface (drawers, usage, Desk), a `SetupWindow`, a pause for usage in `WidgetViewModel`, and a paste entry on `DeskDesignService`. Drawers keep `drawers.enabled`; the Desk keeps `desk_enabled`, now written by setup as `desktop || drawers`.

**Tech Stack:** .NET 10, WPF, CommunityToolkit.Mvvm, System.Text.Json nodes, xUnit.

**Spec:** `docs/superpowers/specs/2026-10-31-setup-design.md` (read it with this plan; section numbers below are the spec's).

## Global Constraints

- Windows only, under `windows-dotnet/`. Nothing in `mac/` or `vscode/` changes.
- CRLF working tree, LF index (`core.autocrlf=true`): never `sed -i` a tracked file; use the Edit tool or a Python rewrite.
- Settings live in `settings.json` through `SettingsStore`; new keys: `setup` = `{ "desktop": bool, "usage": { "claude": bool } }`. `drawers.enabled` and `desk_enabled` keep their meaning. The `just_the_desk` keys stay in the file and are never read again (spec 1, Migration).
- The MCP project does not change: no new `Compile Include` in `Sanduhr.Mcp.csproj`, so `TrustBoundaryTests` stays as it is. New Core files are App-only.
- A Desk design never moves, hides or drops a drawer (`DeskDesignDrawerTests`); a pasted answer's drawers part is separate (spec 3).
- Copy: plain English, sentence case, no em dashes, ends with a period where it is a sentence. The AI chat copy says "any AI chat" and names no product. Claude is named only on the usage tile's source, with the trademark line (`SetupCopy.ClaudeTrademark`).
- Every control has an accessible name (`AutomationProperties.Name`), light mode works (10.1.4.4).
- Streamer mode: nothing on the setup screen or the paste window draws a file name, path, account label or usage.
- What's New card bodies: at most 200 characters, at most two sentences, end with ".", no em dash, glyph one private-use character (`WhatsNewCardsTests`).
- Tests: Core `dotnet test windows-dotnet/tests/Sanduhr.Tests/Sanduhr.Tests.csproj --filter <Name>`; App `dotnet test windows-dotnet/tests/Sanduhr.App.Tests/Sanduhr.App.Tests.csproj -c Release --filter <Name>` (Release, so a running dev `Sanduhr.exe` does not lock the Debug build). Run from the repo root.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Usage off and the Desk turned off on the Desk page:** the next launch must still show something. The widget starts hidden only when usage is off and `desk_enabled` is on (Task 4, `SetupLaunch.WidgetStartsHidden`).
2. **Unticking drawers where turning off fails** (no free name, or a refused confirmation): the other choices still apply, drawers stays ticked, and the result line names what happened (Task 6).
3. **Signing in from Settings, Accounts while usage is off:** adding an account turns Claude usage on and shows the widget, so a sign-in never vanishes (Task 4).
4. **A chat answer wrapped in prose and ```json fences, or holding two blocks:** the reader takes the first block that parses and says how many it found (Task 9).
5. **First run closed with the window's X:** the same as Not now. Nothing is saved, and setup opens again next launch (Task 7).

```csharp
using System.Text.Json.Nodes;

namespace Sanduhr.Core;

/// <summary>
/// What Sanduhr shows (the setup spec, section 1): the Desk's own pieces and each usage source. Drawers keep their own switch
/// (<c>drawers.enabled</c>); the Desk runs when desktop or drawers is on. settings.json <c>setup</c>:
/// <c>{ "desktop": bool, "usage": { "claude": bool } }</c>. Absent means no setup has been made yet (a first run).
/// </summary>
public sealed record SetupSettings(bool Desktop, IReadOnlyDictionary<string, bool> Usage)
{
    public const string Key = "setup";
    public const string Claude = "claude";

    public bool ClaudeUsage => Usage.TryGetValue(Claude, out var on) && on;

    /// <summary>Any usage source on.</summary>
    public bool UsageOn => Usage.Values.Any(v => v);

    public SetupSettings WithClaude(bool on) =>
        this with { Usage = new Dictionary<string, bool>(Usage, StringComparer.Ordinal) { [Claude] = on } };

    public JsonObject Encode()
    {
        var usage = new JsonObject();
        foreach (var (source, on) in Usage.OrderBy(p => p.Key, StringComparer.Ordinal)) usage[source] = on;
        return new JsonObject { ["desktop"] = Desktop, ["usage"] = usage };
    }

    /// <summary>Decoded entry by entry: an entry that is missing or not a bool keeps <paramref name="fallback"/>'s value, so a damaged
    /// file never reads as nothing ticked.</summary>
    public static SetupSettings Decode(JsonNode? node, SetupSettings fallback)
    {
        if (node is not JsonObject o) return fallback;
        bool desktop = SettingsJson.Bool(o, "desktop", fallback.Desktop);
        var usage = new Dictionary<string, bool>(fallback.Usage, StringComparer.Ordinal);
        if (o["usage"] is JsonObject u)
            foreach (var (source, value) in u)
                if (value is JsonValue v && v.TryGetValue<bool>(out var on)) usage[source] = on;
        return new SetupSettings(desktop, usage);
    }
}

/// <summary>The three ticks on the setup screen (spec 2). Desktop reads as ticked only while the Desk runs (spec 1, the Desk page's own switch).</summary>
public sealed record SetupChoices(bool Desktop, bool Drawers, bool ClaudeUsage)
{
    /// <summary>A first run's ticks: the desktop and drawers, no usage.</summary>
    public static SetupChoices FirstRun { get; } = new(true, true, false);

    public bool AnyTicked => Desktop || Drawers || ClaudeUsage;

    /// <summary>The Desk runs whenever desktop or drawers is ticked.</summary>
    public bool DeskRuns => Desktop || Drawers;

    public static SetupChoices Of(SetupSettings s, bool drawersOn, bool deskEnabled) =>
        new(s.Desktop && deskEnabled, drawersOn, s.ClaudeUsage);

    /// <summary>The stored setup for these ticks; sources this build does not show keep their value from <paramref name="before"/>.</summary>
    public SetupSettings ToSettings(SetupSettings? before)
    {
        var usage = before is null
            ? new Dictionary<string, bool>(StringComparer.Ordinal)
            : new Dictionary<string, bool>(before.Usage, StringComparer.Ordinal);
        usage[SetupSettings.Claude] = ClaudeUsage;
        return new SetupSettings(Desktop, usage);
    }
}

/// <summary>What the first launch of a setup build makes of an older settings file (spec 1, Migration).</summary>
public sealed record SetupMigrationResult(SetupSettings Setup, bool DeskOn, bool ReminderOn);

public static class SetupMigration
{
    /// <summary>Null for a first run (no account, no Just the Desk): the setup screen opens. An account wins over Just the Desk,
    /// as signing in did. The sign-in reminder comes back only where Just the Desk had silenced it.</summary>
    public static SetupMigrationResult? From(bool hasAccount, bool justTheDesk, bool silencedReminder, bool deskEnabled)
    {
        if (hasAccount)
            return new(new SetupSettings(deskEnabled, new Dictionary<string, bool> { [SetupSettings.Claude] = true }), deskEnabled,
                justTheDesk && silencedReminder);
        if (justTheDesk)
            return new(new SetupSettings(true, new Dictionary<string, bool> { [SetupSettings.Claude] = false }), true, silencedReminder);
        return null;
    }
}

public static class SetupLaunch
{
    /// <summary>No setup yet: the setup screen opens first.</summary>
    public static bool OpensSetup(SetupSettings? setup) => setup is null;

    /// <summary>The widget starts hidden (the tray is the way back) with usage off and the Desk running; with the Desk off as well
    /// the widget shows, so a launch never shows nothing. Before any setup the setup screen is what shows.</summary>
    public static bool WidgetStartsHidden(SetupSettings? setup, bool deskEnabled) =>
        setup is null || (!setup.UsageOn && deskEnabled);
}
```

    /// <summary>The setup (setup spec, section 1): null when no setup has been made yet, a first run. Decoded entry by entry; an
    /// unreadable entry takes what the migration would say for it.</summary>
    public SetupSettings? LoadSetup()
    {
        var root = Read();
        if (root[SetupSettings.Key] is not { } node) return null;
        var fallback = SetupMigration.From(true, false, false, ReadBool(root, "desk_enabled", false))!.Setup;
        return SetupSettings.Decode(node, fallback);
    }

    public void SaveSetup(SetupSettings setup)
    {
        var root = Read();
        root[SetupSettings.Key] = setup.Encode();
        Write(root);
    }

    /// <summary>Runs once, on the first launch of a setup build (spec 1, Migration): writes <c>setup</c> only when it is absent and
    /// the file has an account or Just the Desk. The <c>just_the_desk</c> keys stay. True when it wrote.</summary>
    public bool MigrateSetup(bool hasAccount)
    {
        var root = Read();
        if (root[SetupSettings.Key] is not null) return false;
        var jtd = LoadJustTheDesk();
        var m = SetupMigration.From(hasAccount, jtd.On, jtd.SilencedReminder, ReadBool(root, "desk_enabled", false));
        if (m is null) return false;
        SaveSetup(m.Setup);
        if (m.DeskOn) SaveDesk(LoadDesk() with { Enabled = true });
        if (m.ReminderOn) SaveDeskSignInReminder(true);
        return true;
    }

/// <summary>What a change says before Continue applies it (spec 4): one line per tick taken away.</summary>
public static class SetupChange
{
    public static IReadOnlyList<string> Lines(SetupChoices before, SetupChoices after, int drawerFiles, bool addonsInstalled)
    {
        var lines = new List<string>();
        if (before.Desktop && !after.Desktop) lines.Add(SetupCopy.DesktopOffLine);
        if (before.Drawers && !after.Drawers && drawerFiles > 0) lines.Add(SetupCopy.DrawersOffLine(drawerFiles));
        if (before.ClaudeUsage && !after.ClaudeUsage)

/// <summary>Turning drawers off: whether they are off now, and the line to show.</summary>
internal sealed record SetupDrawersOff(bool Off, string? Line);

/// <summary>Applies the setup screen's ticks one thing at a time (spec 2, Continue): drawers off first (it can be refused), then the
/// saved choices and the Desk, drawers on, usage, and last the first drawers review.</summary>
internal sealed class SetupService(SettingsStore store, ISetupHost host)
{
    public SetupChoices Current()
    {
        var s = store.LoadSetup() ?? SetupChoices.FirstRun.ToSettings(null) with { Desktop = false };
        return SetupChoices.Of(s, host.DrawersOn, store.LoadDesk().Enabled);
    }

    public IReadOnlyList<string> Preview(SetupChoices after) =>
        SetupChange.Lines(Current(), after, host.DrawerFiles, host.AddOnsInstalled);

    public SetupResult Apply(SetupChoices after)
    {
        if (SetupChange.Blocked(after) is { } blocked) return new SetupResult(Current(), [blocked], false);
        var lines = new List<string>();

        bool drawers = after.Drawers;
        if (!after.Drawers && host.DrawersOn)
        {
            var off = host.TurnOffDrawers();
            if (off.Line is { } line) lines.Add(line);
            drawers = !off.Off;
        }

        var now = after with { Drawers = drawers };
        store.SaveSetup(now.ToSettings(store.LoadSetup()));
        var desk = store.LoadDesk();
        if (desk.Enabled != now.DeskRuns) store.SaveDesk(desk with { Enabled = now.DeskRuns });

        if (host.UsageOn != now.ClaudeUsage) host.SetUsage(now.ClaudeUsage);
        bool turnedOn = now.Drawers && !host.DrawersOn;
        if (turnedOn) host.TurnOnDrawers();
        host.ReloadDesk();

        bool review = false;
        if (now.Drawers && !host.DrawersEverSorted)
        {
            var said = host.SortNow();
            review = said is null;
            if (said is not null && said != DrawerReview.NothingToSort) lines.Add(said);
        }
        return new SetupResult(now, lines, review);
    }

namespace Sanduhr.App.ViewModels;

/// <summary>Set up Sanduhr (setup spec, sections 2 and 4): three ticks, the lines a change says, Continue and Not now or Cancel.</summary>
public sealed partial class SetupViewModel : ObservableObject
{
    private readonly SetupService _service;

    internal SetupViewModel(SetupService service, bool firstRun)
    {
        _service = service;
        FirstRun = firstRun;
        var now = firstRun ? SetupChoices.FirstRun : service.Current();
        _desktop = now.Desktop;
        _drawers = now.Drawers;
        _claudeUsage = now.ClaudeUsage;
        Refresh();
    }

    public bool FirstRun { get; }
    public string DismissLabel => FirstRun ? SetupCopy.NotNow : SetupCopy.Cancel;
    public ObservableCollection<string> ChangeLines { get; } = [];
    public bool Saved { get; private set; }

    [ObservableProperty] private bool _desktop;
    [ObservableProperty] private bool _drawers;
    [ObservableProperty] private bool _claudeUsage;
    [ObservableProperty] private string? _blocked;

    public bool CanContinue => Blocked is null;

    partial void OnDesktopChanged(bool value) => Refresh();
    partial void OnDrawersChanged(bool value) => Refresh();
    partial void OnClaudeUsageChanged(bool value) => Refresh();
    partial void OnBlockedChanged(string? value) { OnPropertyChanged(nameof(CanContinue)); ContinueCommand.NotifyCanExecuteChanged(); }

    private SetupChoices Choices => new(Desktop, Drawers, ClaudeUsage);

    private void Refresh()
    {
        Blocked = SetupChange.Blocked(Choices);
        ChangeLines.Clear();
        if (!FirstRun) foreach (var line in _service.Preview(Choices)) ChangeLines.Add(line);
    }

    public event Action<SetupResult>? Applied;
    public event Action? Dismissed;
    public Action? DesignWithChatRequested { get; set; }

    [RelayCommand(CanExecute = nameof(CanContinue))]
    private void Continue()
    {
        var result = _service.Apply(Choices);
        Saved = true;
        Applied?.Invoke(result);
    }

    [RelayCommand]
    private void Dismiss() => Dismissed?.Invoke();

    [RelayCommand]
    private void DesignWithChat() => DesignWithChatRequested?.Invoke();

```csharp
using System.Text.Json;
using System.Text.Json.Nodes;

namespace Sanduhr.Core;

/// <summary>What a pasted AI chat answer held (setup spec, section 3): its Desk part (checked later by <see cref="DeskDesign.Validate(JsonNode?, DeskDesignContext)"/>),
/// its drawer rules, the names the rules gave their drawers, every problem by field, and how many JSON blocks the paste held.</summary>
public sealed record PastedSetupRead(JsonNode? Desk, IReadOnlyList<DrawerRule>? Rules, IReadOnlyList<string> RuleDrawerNames,
    IReadOnlyList<DeskReason> Reasons, int Blocks)
{
    public bool Ok => Reasons.Count == 0 && (Desk is not null || Rules is not null);
}

public static class PastedSetup
{
    public const int MaxRules = 20;
    public const int MaxDays = 3650;

    private static readonly Dictionary<string, DrawerRuleKind> Kinds = new(StringComparer.Ordinal)
    {
        ["screenshots"] = DrawerRuleKind.Screenshots, ["images"] = DrawerRuleKind.Images, ["documents"] = DrawerRuleKind.Documents,
        ["installers"] = DrawerRuleKind.Installers, ["archives"] = DrawerRuleKind.Archives, ["shortcuts"] = DrawerRuleKind.Shortcuts,
        ["older_than"] = DrawerRuleKind.OlderThan, ["name_contains"] = DrawerRuleKind.NameContains,
        ["name_starts_with"] = DrawerRuleKind.NameStartsWith,
    };

    public static PastedSetupRead Read(string raw)
    {
        var blocks = Blocks(raw ?? "").ToList();
        var first = blocks.FirstOrDefault(b => b is JsonObject o && (o.ContainsKey("desk") || o.ContainsKey("drawers"))) as JsonObject;
        if (first is null)
            return new(null, null, [], [new DeskReason("design", "no Sanduhr block found; ask the chat for one JSON block with desk or drawers")], blocks.Count);

        var reasons = new List<DeskReason>();
        foreach (var (key, _) in first)
            if (key is not ("desk" or "drawers")) reasons.Add(new DeskReason(key, "is not a part; the parts are desk and drawers"));

        JsonNode? desk = first["desk"]?.DeepClone();
        if (first.ContainsKey("desk") && desk is not JsonObject) reasons.Add(new DeskReason("desk", "must be an object"));

        List<DrawerRule>? rules = null;
        var names = new List<string>();
        if (first["drawers"] is { } d)
        {
            if (d is not JsonObject dobj || dobj["rules"] is not JsonArray arr)
                reasons.Add(new DeskReason("drawers", "must be { \"rules\": [ ... ] }"));
            else if (arr.Count > MaxRules)
                reasons.Add(new DeskReason("drawers.rules", $"has {arr.Count} rules; at most {MaxRules}"));
            else
            {
                rules = [];
                for (int i = 0; i < arr.Count; i++)
                    if (Rule(arr[i], $"drawers.rules[{i}]", reasons) is { } rule) { rules.Add(rule.Rule); names.Add(rule.Name); }
            }
        }
        return new(desk, rules, names, reasons, blocks.Count);
    }

    private static (DrawerRule Rule, string Name)? Rule(JsonNode? node, string at, List<DeskReason> reasons)
    {
        if (node is not JsonObject o) { reasons.Add(new DeskReason(at, "must be an object")); return null; }
        int before = reasons.Count;
        string? kindWord = Str(o["kind"]);
        if (kindWord is null || !Kinds.TryGetValue(kindWord, out var kind))
        {
            reasons.Add(new DeskReason(at + ".kind", "must be one of " + string.Join(", ", Kinds.Keys)));
            kind = default;
        }
        string? name = Str(o["drawer"])?.Trim();
        if (name is null || !DrawerNames.IsValid(name) || name.Contains(':') || name.Contains('\\') || name.Contains('/'))
            reasons.Add(new DeskReason(at + ".drawer", "must be a short folder name, not a path"));
        string? text = Str(o["text"])?.Trim();
        if (kind is DrawerRuleKind.NameContains or DrawerRuleKind.NameStartsWith && string.IsNullOrEmpty(text))
            reasons.Add(new DeskReason(at + ".text", "is needed for " + kindWord));
        if (text is { Length: > 60 }) reasons.Add(new DeskReason(at + ".text", "is longer than 60 characters"));
        int days = 30;
        if (kind == DrawerRuleKind.OlderThan)
        {
            if (o["days"] is JsonValue v && v.TryGetValue<int>(out var n) && n is >= 1 and <= MaxDays) days = n;
            else reasons.Add(new DeskReason(at + ".days", $"must be a whole number from 1 to {MaxDays}"));
        }
        if (reasons.Count > before) return null;
        return (new DrawerRule(kind, DrawerIds.From(name!), Text: kind is DrawerRuleKind.NameContains or DrawerRuleKind.NameStartsWith ? text : null, Days: days), name!);
    }

    private static string? Str(JsonNode? n) => n is JsonValue v && v.TryGetValue<string>(out var s) ? s : null;

    /// <summary>Every top-level JSON object in the paste, in order: a scan for balanced braces outside strings, each parsed alone.</summary>
    private static IEnumerable<JsonNode> Blocks(string raw)
    {
        for (int i = 0; i < raw.Length; i++)
        {
            if (raw[i] != '{') continue;
            int depth = 0, end = -1;
            bool inString = false, escaped = false;
            for (int j = i; j < raw.Length; j++)
            {
                char c = raw[j];
                if (inString) { if (escaped) escaped = false; else if (c == '\\') escaped = true; else if (c == '"') inString = false; continue; }
                if (c == '"') inString = true;
                else if (c == '{') depth++;
                else if (c == '}' && --depth == 0) { end = j; break; }
            }
            if (end < 0) yield break;
            JsonNode? node = null;
            try { node = JsonNode.Parse(raw[i..(end + 1)]); } catch (JsonException) { }
            if (node is not null) { yield return node; i = end; }
        }
    }
}
```

`DrawerRule`'s default `Days` is 30; a non-`older_than` rule keeps 30 so `new DrawerRule(DrawerRuleKind.Images, "photos")` equals the parsed rule. `With_two_blocks...` counts `{not json}` as not a block (it fails to parse and the scan moves on one character), so `Blocks == 2`.
