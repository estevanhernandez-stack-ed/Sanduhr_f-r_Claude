## The `/reflect` finding

"Reflect with Claude" (announced 2026-07-09, beta) is a **claude.ai / desktop-app Settings feature**, not a Claude Code CLI command — usage-pattern visualization across topics and tasks, 1–12 month views, Free/Pro/Max with Memory enabled. There is no `/reflect` in the CLI. Implication: its data likely sits behind a claude.ai endpoint that Sanduhr's WebView2 transport could poll once discovered, same as the usage and routines endpoints. The Usage Vault (WS-C) is therefore designed **source-agnostic** so a Reflect source slots in when the endpoint surfaces. `/usage` (CLI) is real and headless-capturable (`claude -p "/usage" --output-format json`), but its plan data is the same endpoint Sanduhr already polls — the durable-storage half of the note is where the value is.

## New feature slate (deduplicated, 30 → 24, ranked)

Two ideas were each pitched independently by two lenses — treated as one candidate with double the signal: *Sanduhr Mode ≡ Session Hourglass*, *Subscription ROI meter ≡ Plan Value Meter*.

### Tier 1 — next wave after the workstreams

| Candidate | Effort | The hook |
|---|---|---|
| **Statusline Bridge** | S | Sanduhr writes a sanitized `snapshot.json`; a one-click-installed Claude Code statusline renders `wk 62% · opus 41% · resets Fri 7p` under the prompt. Only Sanduhr knows the real cap numbers — puts them where the burning happens |
| **Sanduhr MCP server** | M | Read-only stdio MCP (`get_usage`, `get_reset_schedule`, `get_local_burn_by_project`) so Claude itself checks the cap before spawning subagents or picking Opus vs Sonnet. No other monitor makes the agent quota-aware. Shares the snapshot seam with Statusline Bridge |
| **Sanduhr Mode** (usage-as-sand) | M | The brand becomes the display: weekly cap as a live hourglass, grains falling at measured burn rate. Reuses the focus timer's shipped sand sim pointed at UsageFetcher. Pitched independently by two lenses; the identity visual no competitor can copy without becoming a clone. Needs occlusion/battery throttling |
| **Plan Value Meter (ROI)** | S–M | "Your Max plan did $142 of API-equivalent work this week" — the most-screenshotted number in the space, native and themed. Pricing table as updatable JSON; must label cache-token exclusion honestly |
