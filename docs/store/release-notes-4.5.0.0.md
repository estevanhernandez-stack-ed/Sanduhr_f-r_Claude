## Sanduhr für Claude 4.5 (Windows)

**Download:** [`626Labs.Sanduhr-win-Setup.exe`](https://github.com/estevanhernandez-stack-ed/Sanduhr_f-r_Claude/releases/download/v4.5.0/626Labs.Sanduhr-win-Setup.exe) (per-user install). **On 3.8 or later, you don't need to download anything:** Sanduhr fetches this update in the background and offers **Restart to update** when it is ready. **Microsoft Store installs update through the Store.** The `.msix` on this page is an unsigned build artifact and will not install by double-click; see [INSTALL.md](https://github.com/estevanhernandez-stack-ed/Sanduhr_f-r_Claude/blob/main/INSTALL.md).

### What's new

- **Sanduhr works without Claude.** A new install opens **Set up Sanduhr**: a nicer desktop, drawers for your files, your AI usage, or any mix. No account, no sign-in screen, no meter unless you want one. Change it any time from the tray or Settings.
- **Drawers.** Themed panels on your desktop, each a real folder. Built-in rules sort screenshots, pictures, documents, installers, archives, shortcuts and old files, but only after you review the plan, and **Undo** puts them back. Turning drawers off returns every file to the Desktop.
- **Drawers that blend in.** Pick **Solid**, **Glass**, **Outline** or **Bare** and an opacity. Drawers snap to each other and the screen edges, keep clear of your desktop icons, and **Tidy drawers** lines them up.
- **Design it with an AI chat.** Copy a prompt into any AI chat, answer its questions, and paste its answer back to style your Desk and drawers. Preview before anything changes.
- **A real tray icon with usage off:** the Sanduhr hourglass instead of dashes.

Already using Sanduhr? Nothing changes on update. The What's New card **Choose what Sanduhr shows** opens Set up Sanduhr when you want it.

Nothing new leaves your PC: 4.5 adds no destination and no capability. Drawers only move files on your own Desktop, and only when you say so.

### Known issues

- Store installs: if the update won't install (error 0x80073D02), restart Windows and try again.
- Setup.exe is not code-signed, so SmartScreen shows "Windows protected your PC" on first install: More info → Run anyway. The Microsoft Store package is the signed path.
