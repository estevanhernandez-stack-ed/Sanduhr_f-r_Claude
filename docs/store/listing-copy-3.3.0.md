## What's new in this version

```
Claude Fable 5 is now part of Max and Team Premium plans — with its own
weekly allowance. Sanduhr already shows it.

- New: a "Weekly - Fable" meter appears automatically, tracking your Fable
  allowance alongside your other limits. When Anthropic adds a limit for any
  new model, Sanduhr picks it up on its own — no update needed.
- Easier sign-in for Google users: choose "Continue with email" and enter
  the code Anthropic emails you — right inside the app. Step-by-step
  guidance included. No more cookie hunting.
- Quieter alerts: per-model limits alert silently by default (your main
  usage pools still chime). A new checkbox in Settings brings the sound
  back if you want it.
- Smoother account switching, with an automatic reconnect.

Independent third-party tool. Sanduhr für Claude is not affiliated with,
endorsed by, or associated with Anthropic PBC. "Claude" and "claude.ai" are
trademarks of Anthropic PBC, used nominatively to describe what this tool
integrates with.
```
